# WALLY: CRYPTO SMACKDOWN — Asset Manifest & Licenses

This document is the truthful manifest of every asset in the game, and the
audit performed to certify it.

## Summary

**Every visual, audio, and animation asset is procedurally generated at runtime
by first-party code in this repository.** There are no bundled images, models,
audio files, video files, or fonts — first-party or third-party. The only
third-party code is the three runtime/build dependencies listed below, all
MIT-licensed. The game makes no network requests of any kind.

## First-party procedural assets (MIT, this repository)

| Asset class | How it is produced | Where |
|---|---|---|
| Character models & rigs | Low-poly `three` primitives assembled in code, per fighter | `src/characters/*.js` |
| Animation | Procedural keyframe clips (euler tracks) defined in code, blended by a shared animator | `src/characters/*.js`, `src/combat/Animator.js` |
| Arenas, skies, crowds, props | Generated geometry, vertex colors, and Canvas 2D procedural textures | `src/arenas/*.js`, `src/combat/Props.js` |
| Particles & effects | Generated meshes/sprites | `src/combat/Particles.js` |
| UI portraits & backdrops | Drawn at runtime with Canvas 2D | `src/ui/uiKit.js`, `src/ui/MenuBackdrop.js` |
| Music (title, menus, results, one battle theme per arena) | Synthesized with the Web Audio API — oscillators, noise, envelopes; no samples | `src/audio/music.js`, `src/audio/synth.js` |
| Sound effects & crowd | Synthesized with the Web Audio API; no samples | `src/audio/sfx.js`, `src/audio/crowd.js` |
| Announcer voice | Browser SpeechSynthesis (the user's local OS voices), mangled in-engine, with a fully synthesized fallback | `src/audio/voice.js` |
| Fonts | **User system fonts only**, via CSS font stacks (`Impact, 'Arial Black', Haettenschweiler, 'Franklin Gothic Bold', sans-serif` and `'Courier New', monospace`). No font files are bundled or fetched. | `src/ui/ui.css` |

All of the above is original code written for this project and released under
the same MIT license as the rest of the repository (see `package.json`).

## Third-party dependencies

| Package | Version | Role | License | License text |
|---|---|---|---|---|
| `three` | ^0.166.1 | 3D rendering | MIT | `node_modules/three/LICENSE` |
| `cannon-es` | ^0.20.0 | Physics | MIT | `node_modules/cannon-es/LICENSE` |
| `vite` | ^5.4.0 | Dev server / bundler (**development only**, not shipped) | MIT | `node_modules/vite/LICENSE.md` |

`three` and `cannon-es` are the only code bundled into a production build
(along with this repository's own source). Vite and its transitive build
tooling run at development/build time only. None of these packages contribute
art, audio, or font assets to the game.

Browser platform APIs used (not dependencies): WebGL via three, Web Audio,
SpeechSynthesis, Gamepad, localStorage, Canvas 2D.

## Audit

Performed 2026-07-29 against the full repository (`src/`, `index.html`,
`vite.config.js`) to certify the claims above:

1. **No remote resources:** `grep -rn "http://\|https://" src index.html
   vite.config.js` — zero matches. No CDN scripts, no remote images, fonts, or
   media.
2. **No embedded binary assets:** grep for `base64`, `data:image`,
   `data:audio`, `data:font` — zero matches. Nothing is smuggled in as a data
   URI.
3. **No font files:** grep for `@font-face`, `FontFace`, `.woff`, `.ttf`,
   `.otf` — zero matches. The only font references are the system-font CSS
   stacks in `src/ui/ui.css`.
4. **No media/model files imported or referenced:** grep for `.png`, `.jpg`,
   `.gif`, `.svg`, `.mp3`, `.wav`, `.ogg`, `.glb`, `.gltf`, `.fbx` — zero
   asset references (the only textual matches are variable names like `waveR`
   in arena code).
5. **No network calls:** grep for `fetch(`, `XMLHttpRequest`, `WebSocket`, and
   dynamic `import(` — zero matches.
6. **File census:** the only non-JavaScript file under `src/` is
   `src/ui/ui.css`. `index.html` contains no external references.

Conclusion: **no third-party assets exist in this repository**; everything the
player sees and hears is generated by first-party MIT-licensed code plus the
MIT-licensed libraries above.
